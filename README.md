# Ideal Braking Curve

This program calculates and plots the ideal braking curve for our Formula Student car. It works out the front and rear braking forces for tyre friction coefficients from 0 to 2, prints them in a table, and saves a graph.

## Requirements

- Python 3
- numpy
- matplotlib

## How to run

1. Download the project and open a terminal in the project folder.
2. Install the libraries:

```
pip install -r requirements.txt
```

3. Run the program:

```
python main.py
```

The results are printed in the terminal. The graph opens in a window and is saved to `plots/ideal_braking_curve.png`.

## Files

- `main.py` - the program
- `requirements.txt` - libraries needed
- `plots/ideal_braking_curve.png` - the graph
- `report.pdf` - the report
